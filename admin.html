Configuración inicial

Conecta la base

Una sola vez. Después entras con tu correo y contraseña.

  1. Crea el proyecto en supabase.com
  2. SQL Editor → pega supabase-schema.sql → Run
  3. Authentication → Users → Add user: tu cuenta de administrador
  4. Copia los dos valores del botón Connect o de Settings → API Keys

Usa la clave publishable o anon. Nunca la secret ni la service_role. Al conectar te descargo el config.js listo.
